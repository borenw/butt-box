# Butt Box — a box full of tiny games

A cardboard-box arcade for phones and desktop.

- **Climb the Mountain**: carry the red flag up the ledges and plant it in the circle at the summit to earn a coin.
- **Halloween Mountain**: a night climb with bats, ghosts and pumpkins, steered with a drag ball.
- **Shop**: spend coins on a Spring, a Jetpack, a Cat costume or a Witch's hat. Items last one game; coins carry over.

Controls: ◀ ▶ / A D / arrow keys to walk, JUMP / W / Space to hop.

**Live:** https://borenw.github.io/butt-box/

Single self-contained `index.html`, no build step. Progress is saved in browser storage.
